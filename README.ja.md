## 自己紹介

インタラクティブなグラフィックスから AI アプリケーションまで、Web・モバイル向けのプロダクトを開発しています。WebGL・GLSL によるレンダリング、フロントエンドの UI、バックエンドの開発に携わっています。

## 開発分野

### グラフィックスとインタラクティブツール

室内や商品のビジュアライゼーション、キャンバス UI、形状編集ツール。再利用可能なレンダリングモジュールや SDK の組み込みにも取り組んでいます。

### AI アプリケーション

大規模言語モデルを活用した対話型プロダクト。ストリーミング応答、会話メモリの要約、サブスクリプション機能を扱っています。

### Web とクロスプラットフォーム開発

Web アプリ、管理画面、Flutter クライアント、SwiftUI によるネイティブアプリと、それらを支える API、認証、データストレージ。

## 現在の取り組み

AI を活用した Web ビジュアライゼーションを探求しています。インタラクション、レンダリング品質、パフォーマンスを重視しています。
